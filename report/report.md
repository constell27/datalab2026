### bitSwap

```c
int ns = n << 3;
    int ms = m << 3;
    int diff = ((x >> ns) ^ (x >> ms)) & 255;
    return x ^ (diff << ns) ^ (diff << ms);
```

这题我想到了可以借助异或的性质。因为异或满足 a ^ (a ^ b) = b 和 b ^ (a ^ b) = a。所以可以首先通过n<<3和m<<3将字节编号转换为位移量，再将两个目标字节分别右移到最低位，异或后与255按位与，只保留低8位，得到两个字节的差异 diff。再将diff分别左移回两个目标位置，再与原数异或，就能让两个字节互相变成对方；其他位置与零异或，保持不变。

### reverse

```c
unsigned result = 0;
    int n = 32;
    while (n) {
        result = (result << 1) | (v & 1);
        v = v >> 1;
        n = n - 1;
    }
    return result;
```

这题思路很简单，主要是想到&1取数比较有意思。将result初始化为零，循环处理原数的全部32位。每轮先用v&1取出原数的最低位，再将result左移一位，在右侧腾出位置，通过按位或放入刚取出的位，然后将v右移一位，丢掉已经处理的位。这样，最先取出的原最低位会随着后续循环不断向左移动，最终成为结果的最高位，实现整体倒序。循环必须执行完整的32次，因为原数高位的零也需要参与反转；v为无符号数，右移时左侧会补零。
